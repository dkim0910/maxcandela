# Paid demand and rankings for Mac menu-bar utilities (2025–2026)

Snapshot date for everything measured directly: **2026-11-22** (Mac App Store chart pages carried a feed timestamp of 2026-11-21; Setapp and GitHub numbers were read the same day). "Measured" = a number read off a store, API or vendor page. "Opinion" = an editor's pick in a roundup.

**How the measurements were taken.** The charts came from Apple's public web pages, read from the JSON embedded in each page. Those pages carry the top 25 per chart: Utilities is genre 6002 and Productivity is 6007, at `https://apps.apple.com/{cc}/mac/charts/{genre}?chart=top-paid` (the same page also holds the top-free list). Prices came from the iTunes Search/Lookup API (`itunes.apple.com/search?entity=macSoftware`). Setapp rating counts came from the schema.org `ratingCount` / `ratingValue` on each `setapp.com/apps/<slug>` page. GitHub stars came from `api.github.com/repos/<repo>`.

## Q1. Current top paid / top free apps in Mac App Store Utilities and Productivity (US + GB, DE, JP), and which are menu-bar utilities

### Takeaway
Free utility charts are dominated by VPNs, unarchivers and ad blockers. Amphetamine (keep-awake) is the one menu-bar utility that charts in every storefront checked. Paid charts carry more menu-bar and "small system tweak" apps. The repeat paid winners are **Magnet** (window snapping), **Klack** (keyboard sounds), **Maccy** (clipboard, $9.99), **BetterSnapTool**, **HazeOver**, **TextSniper** and **iStat Menus**. Klack is **#7 and Magnet #17 among *all* paid Mac apps in the US**.

## Q4. Mac App Store rating counts for single-purpose menu-bar apps

### Takeaway
**Mac App Store rating counts for Mac-only apps are not publicly readable as of 2026-11-22.** Apple's redesigned web store and the iTunes Search API both return 0 ratings for Mac-only apps, even Editor's Choice Magnet. The usable substitutes are chart rank (Q1), Setapp rating counts (Q2), GitHub stars, and vendor-stated download counts, recorded below. The same lookup also turned up a **critical finding for a sandboxed toolbox: the App Store build of Hidden Bar says it cannot hide menu-bar icons on macOS 27 because the sandbox blocks it, and Octobar (an MAS toolbox) says the same of its icon-hiding module.**

### Cited Findings
- **Ratings unavailable.** `apps.apple.com/us/app/magnet/id441258766` carries `"totalNumberOfRatings":0` and the status "This app hasn't received enough ratings or reviews to display an overview". ### Inferences
- **For MaxCandela specifically:** Hidden Bar's maintainer and Octobar both report that MAS-sandboxed icon hiding stops working on macOS 27, and they use the same divider-status-item technique MaxCandela's "Hide Menu Bar Icons" Pro tool uses. - The GitHub star ranking shows where *free* demand is largest: system monitoring (Stats), external-display control (MonitorControl, BetterDisplay), window snapping (Rectangle), menu-bar hiding (Ice, Hidden Bar), clipboard (Maccy) and per-app audio (Background Music). MAS paid charts favour window snapping, clipboard and keyboard sounds, and system monitoring at a premium (iStat Menus). Display control is a high-demand category that is mostly served outside the MAS.
- Free MAS toolboxes already exist (BarBox Tools, Octobar, and OnlySwitch on GitHub) with feature sets overlapping a menu-bar toolbox: keep awake, clipboard history, timer, generators, IP, audio, color picker. A toolbox's free tier competes with $0, so the paid hook has to be something those lack.

### Inferences
- **Price anchors MAS buyers already accept for a single menu-bar job: $2–$10 one-time.** A $9.99 lifetime toolbox equals *one* Maccy or *two* Magnets. That is competitive if the toolbox clearly replaces two or more paid apps (for example a clipboard manager plus window snapping plus keep-awake), and weak if its paid tools duplicate free ones (BarBox Tools, Octobar free tier, Amphetamine, Hidden Bar).
- The subscription leaders (Paste, Raycast, CleanShot Cloud, Bartender Pro, AlDente Pro) justify recurring fees with sync, cloud or continuous updates. A $0.99/month tier is far below every comparable subscription found. Its value is low friction, not a signal of a premium category.
- The categories with the clearest *paid* evidence (charting on the MAS **and** high Setapp counts) are **window management** (Magnet, BetterSnapTool, Moom), **clipboard** (Maccy, Paste), **OCR / text capture** (TextSniper), **file shelf** (Yoink), **keyboard sounds** (Klack), **focus dimming** (HazeOver), **system monitoring** (iStat Menus) and **battery charge limiting** (AlDente). Charge limiting is direct/Setapp only, probably because it needs a privileged helper, but that was not verified.

- No current MAS price was confirmed for One Switch, coconutBattery (and its Plus tier), AirBuddy, Boom 3D, PopClip, Rectangle Pro or the Octobar Pro IAP.
